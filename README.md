## ⚡ About me

I like taking a problem from the first rough idea to a working demo. I move between models, APIs, and interfaces because I want to see what happens when someone actually uses the system. Lately, I've been exploring offline AI, trustworthy evidence, and tools that help people make better decisions.

Most of what I've built started as a hackathon project — 3 a.m. commits, pitch decks, and prototypes included. If it gets me writing code I haven't written before, I'm in.

**Currently exploring:** deep learning, computer vision, and LLM applications.
