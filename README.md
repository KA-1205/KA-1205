## ⚡ About me

I'm an AI/ML undergraduate focused on machine learning and backend engineering. I work mainly with Python: building model pipelines, connecting retrieval systems, and serving them through APIs. My projects explore fraud detection, offline AI, computer vision, and traceable evidence.

Most of what I've built started as a hackathon project — 3 a.m. commits, pitch decks, and prototypes included. If it gets me writing code I haven't written before, I'm in.

**Currently exploring:** deep learning, computer vision, and LLM applications.
