## ⚡ About me

I'm an AI/ML undergraduate who takes ideas from a rough sketch to a working demo. I move between models, APIs, and interfaces because I want to see what happens when someone actually uses what I've built.

Hackathons push me to learn unfamiliar tools, build with a team under a deadline, and find out what survives beyond the pitch. I care about AI that is useful, explainable, and testable.

## 🧩 More projects

- **[SIH 2026 · Sanchar Saṅgaṇaka](https://github.com/KA-1205/SIH-2026)** — contributed to a team prototype that detects threats in one-way network traffic and streams alerts to an operator console.
- **[Prometheus](https://github.com/KA-1205/prometheus)** — contributed to a fraud-detection system with synthetic transactions, XGBoost and graph models, and weakness-directed retraining. 242/242 tests passing; its benchmark covers eight fraud typologies and six attacks, with two attack types held out from training.
- **[Cerberus](https://github.com/KA-1205/Cerberus)** — a gatekeeper for AI tool registries that tests candidate tools in isolation and records signed verdicts. The repository documents 15 passing integration checks and a seeded poisoned tool being rejected. [App (sign-in)](https://cerberus-wildcards.vercel.app/)
- **[LenderCheck](https://github.com/KA-1205/LenderCheck)** — an interactive **simulation** of a Telegram loan-app verification bot. The public demo uses simulated data across four scenarios. [Demo](https://lendercheck.netlify.app/)
- **[PROVCHAIN](https://github.com/KA-1205/GSC)** — a hackathon prototype for Indian publishers that combines content fingerprints (pHash, Gemini Vision, SHA-256), propagation monitoring, and evidence bundles. Built with FastAPI, React, Google Cloud, and IPFS. [Demo](https://gsc-nomr.vercel.app)
- **[The Second Shift](https://github.com/KA-1205/The-Second-Shift)** — a career re-entry coach concept for women, with skill-gap analysis and flexible-job matching. The current site uses mock data; the Gemini and FastAPI backend is planned. [Demo](https://thesecondshift.vercel.app)
